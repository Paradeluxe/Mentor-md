告诉 Mentor 你的名字, 之后所有批注会标注作者. 也可以留空用"匿名".

Mentor 使用提示

  • 选区批注: 拖选任意文字 → 点 批注 按钮 → 侧栏建批注线程
  • 嵌套回复: 在批注线程里继续回复, 像 docx 一样对话
  • 解决 / 重新打开: 批注可以标记为已解决, 需要时再打开
  • 侧车存储: 批注存为 xxx.md.annotations.json 侧车, 源 .md 保持干净
  • 单 .mentor 包: 像 docx 一样, 选 .mentor 单文件 = md + 批注打包在一起 (内部仍是 content.md + annotations.json)
  • 双模式兼容: 旧 .md + .annotations.json 仍可加载; 新建/另存可选 .mentor
  • 保存: Ctrl+S Chrome/Edge 直接写回原位置; 其他浏览器下载到 xxx.md 同目录
  • 跨刷新重连: 授权过的 .md handle 留在 IndexedDB; 重开应用自动恢复并继续保存

快捷键: Ctrl+B 加粗 · Ctrl+I 斜体 · Ctrl+S 保存

⚙ 设置

超过上限时新批注被拒绝. 0 = 无限制 (perf 可能卡). 200 条时打字已明显卡顿 (实测 108ms p95).
