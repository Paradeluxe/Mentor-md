Mentor 使用提示

  • 选区批注: 拖选任意文字 → 点 批注 / AI → 侧栏建线程
  • 嵌套回复: 在批注线程里继续回复, 像 docx 一样对话
  • 解决 / 重新打开: 批注可以标记为已解决, 需要时再打开
  • 单 .mentor 包: 主路径 — 像 docx 一样, 一个 .mentor = md + 批注 + 图片 (内部 content.md + annotations.json + media/)
  • 图片批注: 点选图片 → 批注; 保存/重开靠 imageAnchors, 不只靠正文文字
  • 双模式兼容: 旧 .md + .annotations.json 侧车仍可加载; 建议另存为 .mentor
  • 离线运行: v1.43.37+ 依赖已本地打包, 无网也可打开编辑
  • 保存: 写回当前文档；无原位写权限时会先说明并推荐 .mentor
  • 另存: 下载 .mentor 副本，不改变原文件
  • 导出 DOCX: 仅正文，不含批注与引用库元数据
  • 跨刷新重连: 授权过的 .md handle 留在 IndexedDB; 重开应用自动恢复并继续保存
  • 正文引文: 从文献库插入；正文点击引文可定位对应文献，缺失 key 会明确标红
  • 文献库: 管理元数据；正文引文使用 Pandoc [@citekey]；改 citekey 会同步正文；导出 BibTeX 给 Pandoc/Zotero
  • Zotero 单条导入: 在 Zotero 选中文献，导出 Better BibTeX (.bib) 或 CSL JSON，再到文献库点「导入文献」。单条记录会先进入确认表单，不会整库覆盖
  • 可移植引用: .mentor 内嵌 references.json + references.bib；不直接读取 zotero.sqlite，无自动 live sync
  • 引文排版: Mentor 提供轻量作者—年份预览；期刊级 APA/CSL 请用 Pandoc citeproc

快捷键: Ctrl+B 加粗 · Ctrl+I 斜体 · Ctrl+S 保存
